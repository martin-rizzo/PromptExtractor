__PromptExtractor (promptex)__ is a lightweight command-line tool and library written in C99 designed to read and display the embedded metadata (prompts, steps, CFG, negative prompts, etc.) from images generated by popular AI tools like Stable Diffusion WebUI (A1111) and ComfyUI.

It supports extracting raw text chunks from image files, parsing structured metadata blocks, and presenting them in a clean, colorized console output.

## ✨ Features

*   **Multi-Format Support:** Extracts metadata from **PNG** (Text Chuncks) and **JPEG** (EXIF User Comment).
*   **AI-Specific Parsers:**
    *   **A1111:** Parses standard Stable Diffusion WebUI metadata.
    *   **ComfyUI:** Parses embedded JSON workflow data (por ahora de manera muy sencilla).
*   **Colorized Output:** ANSI color codes highlight different parameter types for better readability.
*   **Modular Architecture:** Core logic is encapsulated in `libpromptex`, making it reusable for other applications.

## 📦 Installation & Usage

### Building the Project

Ensure you have a C99 compiler and `make` installed.

```bash
# Clone the repository
git clone https://github.com/martin-rizzo/PromptExtractor.git
cd PromptExtractor

# Build the library and the CLI binary
make

# The binary is generated at /bin/promptex and /bin/libpromptex.a
```

### Basic Usage

Run `promptex` followed by the path to one or more image files:

```bash
./bin/promptex path/to/your/image.png
./bin/promptex image1.jpg image2.png
```

### Example Output

```text
[FILE] image.png
├── Prompt: "masterpiece, best quality, 1girl, ..."
├── Negative Prompt: "lowres, bad anatomy, ..."
├── Steps: 20
├── CFG Scale: 7.0
└── Model: v1-5-pruned-emaonly.safetensors [a1111]
```

## Architecture

The project is structured into two main components:

1.  **`libpromptex`**: The core library.
2.  **`src/main.c`**: The CLI entry point that orchestrates the extraction and displays the results.
