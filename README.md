
# PromptExtractor (`promptex`)

> **Extract prompts and generation parameters from AI-generated images.**

`promptex` is a lightweight command-line tool written in C99 designed to read and display the embedded metadata (prompts, steps, CFG, negative prompts, etc.) from images generated by popular AI tools like Stable Diffusion WebUI (A1111) and ComfyUI.

It supports extracting raw text chunks from **PNG** and **JPEG** files, parsing structured metadata blocks, and presenting them in a clean, colorized console output.

## 🚀 Features

*   **Multi-Format Support:** Extracts metadata from **PNG** (Chuncks/ComfyUI JSON) and **JPEG** (EXIF User Comment).
*   **AI-Specific Parsers:**
    *   **A1111:** Parses standard Stable Diffusion WebUI metadata.
    *   **ComfyUI:** Parses embedded JSON workflow data (extensible).
*   **Memory Efficient:** Uses a centralized storage buffer (`_storage`) for string management, ensuring clean memory allocation and easy parsing.
*   **Colorized Output:** ANSI color codes highlight different parameter types for better readability.
*   **Modular Architecture:** Core logic is encapsulated in `libpromptex`, making it reusable for other applications.

## 📦 Installation & Usage

### Building the Project

Ensure you have a C99 compiler and `make` installed. You may need `libyyjson-dev` for ComfyUI JSON support.

```bash
# Clone the repository
git clone https://github.com/yourusername/promptextractor.git
cd promptextractor

# Build the library and the CLI binary
make

# The binary is generated at /bin/promptex
```

### Basic Usage

Run `promptex` followed by the path to one or more image files:

```bash
./bin/promptex path/to/your/image.png
./bin/promptex image1.jpg image2.png
```

### Example Output

```text
[FILE] image.png
├── Prompt: "masterpiece, best quality, 1girl, ..."
├── Negative Prompt: "lowres, bad anatomy, ..."
├── Steps: 20
├── CFG Scale: 7.0
└── Model: v1-5-pruned-emaonly.safetensors [a1111]
```

## 🏗 Architecture

The project is structured into two main components:

1.  **`src/libpromptex`**: The core library containing:
    *   `image_fmt/`: Format-specific parsers (PNG, JPEG, ComfyUI JSON).
    *   `strings/`: Efficient string management and buffer handling.
    *   `params/`: Data structures for storing extracted parameters (`PeParams`).
2.  **`src/main.c`**: The CLI entry point that orchestrates the extraction and displays the results.
